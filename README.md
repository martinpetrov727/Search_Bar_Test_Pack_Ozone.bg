# Ozone.bg – Search Functionality Test Cases

## 📌 Overview
This project contains manual test cases for the search functionality of the Ozone.bg e-commerce platform.

The goal is to validate the behavior of the search bar and ensure accurate, user-friendly results for different types of input.

---

## 🎯 Scope
- Search functionality for guest users
- Input validation
- Search suggestions
- Result relevance and behavior

---

## 🧪 Test Coverage
The test cases include:

- ✅ Positive scenarios (valid keyword search)
- ❌ Negative scenarios (invalid or empty input)
- 🔢 Boundary testing (long input, single character)
- ⚠️ Special character handling
- 🔍 Search suggestions behavior
- ⌨️ Different input methods (button click, Enter key)

---

## 🛠️ Approach
- Manual testing
- Focus on real user interactions
- Validation of UI behavior and system responses

---

## 📂 Structure
Each test case includes:
- Test Case ID
- Title
- Preconditions
- Steps
- Expected Result

- Identify edge cases and unusual inputs

- Validate user experience in e-commerce systems
